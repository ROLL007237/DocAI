# Детекция и распознавание зон на документах, удостоверяющих личность

Проект находит на изображении документа фотографию лица и машиночитаемую зону (MRZ), вырезает их и распознаёт текст MRZ через Tesseract OCR.

## Как работает
1. **YOLO26** находит на документе две зоны: `photo` и `mrz`.
2. Каждая зона вырезается в отдельный файл.
3. **Tesseract OCR** распознаёт текст MRZ.
4. Для каждого документа создаётся отдельная папка с результатами.

## Технологии
- YOLO26 (Ultralytics) — детекция зон
- X-AnyLabeling — разметка данных
- Tesseract OCR 5.5 — распознавание текста
- OpenCV, Python 3.11

## Установка
Установите библиотеки:

pip install ultralytics opencv-python pytesseract

Также нужен Tesseract OCR с английским языком: https://github.com/UB-Mannheim/tesseract/wiki

## Запуск
1. Положить документы в папку incoming/
2. Запустить обработку
python main.py
3. Результаты появятся в output/

## Результат обработки
Для каждого документа создаётся отдельная папка, внутри которой:

- исходное изображение;
- face.jpg — вырезанная фотография;
- mrz.jpg — вырезанная машиночитаемая зона;
- mrz.txt — распознанный текст MRZ;
- boxes.txt — координаты найденных боксов.

## Датасет
Обучение — на синтетических канадских паспортах
(Kaggle), 96 изображений,
два класса: photo, mrz.

Проверка — на японских паспортах (эти данные не участвовали в обучении).

## Результаты
Метрики на валидационной выборке:

- all: Precision 0.999, Recall 1.000, mAP50 0.995, mAP50-95 0.870
- photo: Precision 0.998, Recall 1.000, mAP50 0.995, mAP50-95 0.926
- mrz: Precision 0.999, Recall 1.000, mAP50 0.995, mAP50-95 0.814

Обучение: 50 эпох, YOLO26n, CPU, около 27 минут.

Проверка на новых данных: 20 из 20 японских паспортов обработаны корректно.
